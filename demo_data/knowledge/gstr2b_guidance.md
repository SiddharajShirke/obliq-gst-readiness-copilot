# GSTR-2B Reconciliation Guidance

Source type: official GST guidance, paraphrased for the OBLIQ prototype.

## Purpose

GSTR-2B is an auto-drafted statement used as a reference during input tax credit review. A CA should compare the client purchase register with the downloaded statement before preparing the GST working.

## Reconciliation differences

A purchase-register-only item means the client recorded an invoice that was not found in the uploaded GSTR-2B data. A GSTR-2B-only item means the statement contains an invoice not found in the client register. An amount or date mismatch means both records appear related but important values differ.

OBLIQ must describe these as possible differences requiring CA review. It must not automatically approve or reject input tax credit.
